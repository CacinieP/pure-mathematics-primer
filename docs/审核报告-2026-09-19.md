## 渲染与发布检查

首版的 35 项自动检查通过：14 项数学例子、11 项阅读版构建器、10 项 Wiki 导出器。严格构建生成 39 个 HTML 页面（含 404 页面），1,597 段公式通过 MathJax 渲染，源公式与页面公式比对未发现丢失或增加。

在线阅读版通过严格 MkDocs 构建；检查内部链接、锚点、资源和未被解析的数学定界符。每段数学公式用与页面相同版本的 MathJax 渲染，再把 Markdown 源公式与 HTML 中的数学节点逐一比对，防止公式静默丢失。

Wiki 使用专门的行内数学和数学围栏语法，保护竖线、矩阵换行与代码。章节锚点使用稳定的 ASCII 标识，避免 GitHub Wiki 对中文自定义锚点的二次转码。发布时另检查 GitHub 原生渲染与实际线上页面。

实际浏览器检查发现 GitHub 前端拒绝 `\operatorname`，即使本地 MathJax 与 Markdown 接口检查通过也会显示错误。已将相关命名算子改用 `\mathop{\mathrm{...}}\nolimits`，保留算子语义和间距，并加入自动检查防止再次引入；同时修复伴随定义行尾控制空白的转义问题。
