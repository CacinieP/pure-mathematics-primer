# 纯数学入门：分支地图、逻辑与范畴论

[在线阅读](https://caciniep.github.io/pure-mathematics-primer/) · [GitHub Wiki](https://github.com/CacinieP/pure-mathematics-primer/wiki) · [审核报告](docs/审核报告-2026-09-19.md)

这是一份中文纯数学入门书。它从“这个分支研究什么问题”开始，给出精确定义、可核验的例题、常见误解和继续阅读的路线，重点展开数理逻辑与范畴论。

数学分支没有唯一、封闭的完整清单。本书用主要问题群组织内容，并提供细分方向的检索入口；它不声称用几十章讲完全部数学。范畴论是研究对象与映射的广泛语言，也是独立研究领域，不能简单等同于数理逻辑；二者的联系会通过具体构造说明。

## 从哪里开始

如果刚从高中数学进入大学证明，先读[数学全景地图](00-导读/01-数学全景地图.md)和[证明与学习方法](00-导读/02-证明与学习方法.md)，再从数论、离散数学或命题逻辑进入。分析、几何和数学物理章节会标出所需的微积分知识。

如果主要想学范畴论，建议按“函数与证明 → 群与同态等具体例子 → 对象与态射 → 函子 → 自然变换 → 泛性质 → 伴随 → Yoneda”阅读。读到不熟悉的对象时返回对应分支，不必先学完全部数学。

如果关心数理逻辑，按“命题逻辑 → 谓词与量词 → 集合与无穷 → 模型与证明 → 可计算性与不完备性”推进。始终区分某个模型中为真、所有模型中有效、某个理论中可证明。

## 阅读约定

除非另有说明，采用经典逻辑；集合论背景及其限制见[集合与 ZFC 的边界](02-逻辑与基础/03-集合与ZFC的边界.md)。自然数记为 $\mathbb N=\{0,1,2,\ldots\}$，只取正整数时会明确说明。函数 $f:A\to B$ 的定义域与陪域都属于数据；复合 $g\circ f$ 表示先做 $f$ 再做 $g$。

定理的假设属于定理本身。“直观”“例子”和“证明”承担不同职责：例子帮助理解和检验，完整证明才覆盖其明确声明的范围。章节引用作者开放教材、大学讲义或机构资料作为进一步阅读与核查入口；正文不把外部教材整体复制进来。
